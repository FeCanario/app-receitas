## Resumo do projeto

App web para organizar receitas culinárias. O usuário cria uma conta, explora e busca receitas, cadastra as suas próprias, marca favoritas com estrela e monta uma lista de compras a partir dos ingredientes.

**Requisitos da atividade:** grupo de até 4 pessoas, HTML + Python, JavaScript + React e Gitflow.
